# Notes

A self-contained, single-file notes app. No install, no server, no dependencies.

## Run it

Open `index.html` in any browser — double-click it, or drag it into a browser window.

## How it works

- Notes are saved automatically to your browser's local storage as you type.
- Storage is per-browser, per-machine — notes won't follow you to a different browser or computer.
- Click **Export** to download all notes as a `notes-export.json` backup file.
- Click **+ New note** to start one, or **Delete note** to remove the one you're viewing.
